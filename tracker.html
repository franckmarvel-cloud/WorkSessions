Program Info
📱 Add to iPhone Home Screen
1. Open tracker.html in Safari (not Chrome)
2. Tap the Share button (box with ↑ arrow)
3. Scroll and tap Add to Home Screen
4. Tap Add — done!

It opens full-screen like a native app. The file itself is your backup — keep it in iCloud Drive and re-open it there so Safari's localStorage persists across launches from the home screen icon.
